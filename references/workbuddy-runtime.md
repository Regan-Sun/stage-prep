# WorkBuddy 运行适配

此包已完成格式适配和本地脚本校验；尚未在 WorkBuddy 客户端内实机调用。

## 每次按任务检查能力

1. 定位当前已安装技能目录与用户提供的文件。开发机原始视频路径仅用于溯源，不能假定目标环境存在；缺视频时请用户提供。包内四张静态案例可直接按相对路径读取，其余索引仅用于定位。
2. 规划模式先读取课程规则和 planning.md。保持原稿完整，适应坐姿、单手和小空间；没有走位目的就原位表达。
3. 视频模式检查是否有实际图片理解能力、可执行命令和 Python 3.10+。能列出文件不等于看过图；不能读取图片则停止视觉判断。
4. 用 inspect_media.py 检查 OpenCV；抽帧可用才执行 extract_evidence.py。联络表依赖 Pillow；音频导出依赖 ffmpeg。宿主的工具名称、Shell、解释器路径以实际可用能力为准。
5. 缺依赖先说明并请求必要的安装授权。可在虚拟环境安装 opencv-python-headless 与 Pillow，或安装到技能目录的 .runtime；不要复制 Codex 机器的编译依赖。无 ffmpeg 时不加 --audio。没有音频工具时依字幕做局部判断，缺前后完整句不补写。
6. 报告由 build_report.py 生成，图片为相对路径副本。给出实际保存位置和已观察范围；报告校验不证明教学结论正确。

## 客户端首次验收

- 能发现“大高培演讲助手（上台准备）”并加载参考资料。
- 用坐姿、右手持麦的稿件规划，不安排走位或双手动作；“绝不放弃”不机械配拒绝手势。
- 用十秒可见全身视频试抽帧并真正查看图片，正确标出未听音范围。
- 不知道口播时写未知而非静默；能取得完整台词时，图下前后各两句、当前句加粗。
- 输出图片和时间码可回溯；证据不足不凑缺点。

未完成这些检查前，只能报告“安装包已适配，客户端验收待完成”。
