# 案例库使用

来源：用户提供的 7 段大区演讲、优秀动作萃取报告、29 张定向截图。case-index.json 保存29条候选，并用 `status` 区分核验情况。原始教学文件以题目/演讲者定位，不要求学生电脑具有开发目录。

`static_verified` 只表示该帧的手形和画面字幕可见，不能据此证明整段动作四拍、眼神覆盖或完整走位。`candidate_recheck` 是定位线索，必须取得原视频并复查再引用。未附图的案例不得编造预览或把不存在的文件链接交给用户。

内置四张静态示例：杨海莲的“两年”数字；罗嘉民的“高大威猛”高度；张超自我觉察时胸前手势；宋蕊双掌外推。它们是特定台词下的例子，不是各类别唯一正确动作。

原先“时”的托掌示例仅可确认台词提到现在/过去，不能据此证明空间时间轴；“定”的握拳示例是自豪表达，未必是决心。此两类保留为候选。眼神案例只保留可见朝向，不用单帧证明具体注视对象。步法案例未完整拍到脚部，不作为完整步法标准。

分发给学员前确认示范图片可用范围；也可去掉 assets 图像，只保留文字案例，Skill 核心流程不受影响。学员上传的视频证据不自动加入教学案例库。
