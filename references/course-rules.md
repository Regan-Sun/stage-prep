# 课程规则 v1.0.0

来源优先级：用户最新明确要求 > 20260909《“身”入人心》最终逐字稿 > 摘录一、二、三 > 七人演讲观察案例。下文以章节名定位来源，分发不依赖原作者本机路径。

## 身如松

来源：课程 PPT 8—11；摘录一“上台位置与基本站姿”。

- 定看响：到位后站定；平稳看向听众；连接后开口。开头有意进行场景表演时允许不同设计。
- 五件套：脚底生根、头顶悬绳、双肩开窗、腰系腰带、头戴皇冠。自然舒展，不僵硬。按学员身体条件适配，坐姿可用稳定支撑、肩颈舒展代替脚步要求。
- 晃、倾、踮、缩是可观察行为；晃/踮需连续且相关部位可见，倾/缩不能凭一个故事表演姿态判定为不良习惯。

## 眼传情

来源：课程 PPT 12—14；摘录二“眼神”。

对焦要准、取景要全、转场要稳。按小意群自然更换连接对象，同时照顾区域。Z 字仅为练习选项。区分看听众与看故事中的对象：看高个子、孩子、远处灯光的方向由情境决定，不自动算回避观众。视频里头部方向不等于眼睛具体注视点；单帧不证明覆盖全场。

## 手显势

来源：课程 PPT 15—22；摘录二“手势”。

| 任务 | 适用意图 | 动作选项与边界 |
|---|---|---|
| 说人 | 我、他、你们、我们 | 自指轻触胸前；他有稳定虚拟位置；掌心呈现你们；用开放动作联结我们。避免机械见代词就指 |
| 数 | 数量、顺序 | 手指呈数；结合文化与听众理解，复杂数字可用口头说明 |
| 形 | 大小、长短、轮廓 | 双手量度、抬手示高；注意物体厚度和拿取方式 |
| 位 | 位置、方向 | 开掌呈现方向；同一对象不无故换位置 |
| 时 | 过去、现在、未来 | 按本篇设定空间时间轴；提及年份不代表必须做时间手势 |
| 比 | 两方、前后差异 | 左右两端呈现比较；顺序一致，不叠加多余数数动作 |
| 开 | 开放、邀请 | 手掌自然打开，幅度适配场地 |
| 心 | 自我披露、真诚表达 | 自然回到胸前或向听众送出；无需每次“我”都摸胸 |
| 定 | 坚定、决心 | 有清楚落点的握拳或收束；力量不等于动作更大 |
| 界 | 拒绝、界限 | 掌心向外、清楚停止；按整句含义判断否定词 |
| 招 | 号召、愿景 | 向听众或上前方送出；主题句可有简洁招牌动作 |

左手五问/右手五动只是记忆法。任何一手或双手均可。手持麦时优先单手，避免要求换麦才能完成动作。

动作四拍：语义触发 → 动作成形 → 短暂停留 → 回到中性。准备可以略早于重读词，成形与关键词相配；停留半秒到一秒为练习参考，不能作为所有视频的硬阈值。动作密度以突出信息为准；不追求每句配满。

## 步有方

来源：课程 PPT 23—24；摘录三舞台移动；用户补充。

核心：所有移动都有目的。可服务时间、逻辑、场景、人物关系、情绪转折和互动。开头结尾通常中央靠前并形成回归；是可选默认，不是强制轨迹。

每次移动记录：从哪里到哪里、为什么、在哪句连接语中走、在哪个重点句前站稳。舞台图必须写清观众方向和演讲者左右。区域含义前后一致；过去不必永远在右侧。

向前可以连接、提问、强调、呼吁；向后可以表现退缩或留思考空间，但需具体内容依据。不能从方向推断内心。站定可以有效，无须为时间变化强行走位。狭小场地可由手势、朝向和停顿完成转换。

“震动型”需连续小动作证据；“漫游型”需移动轨迹与语义对照。意图不明时写“暂未发现对应的内容变化”，不要断言“你因为紧张而走动”。跟拍、缩放、镜头切换与人物移动分开。

## 情境与练习

来源：课程 PPT 26—28、29—37；摘录一“送礼物”；摘录三“四个意”。

先问：给听众什么？此刻看见谁、听见什么、感受到什么具体画面？捡湿书练习注意物体厚度、从地面拿起的过程；可先拿实物再移除实物练习。不要凭想象强制所有人都甩水或拍书。

本轮只练一项；说具体身体事实。无意 → 留意 → 刻意 → 随意，用录像观察与短片段重做帮助内化。随意是练习后的自然，不是动作越多越好。7-38-55不作为本 Skill 的评分公式。
