# 演讲上台准备助手

这是一个给演讲者用的“上台前教练”。

## 基本信息

“演讲上台准备助手”帮助你精心设计演讲上台前的准备动作。它支持两种模式：上传演讲稿，结合内容、场地和持麦方式，规划身姿、眼神、手势与走位；上传演练视频，基于可核验的画面与台词，提供带时间码、动作截图和语境说明的半自动复盘。

它不替你机械编排每一个动作，也不做全自动评分，而是帮助你找到值得保留的表现和优先调整的重点。每次练好一个动作，让表达更自然、更有目的、更打动人。

## 它的工作方式

它作为《“身”入人心》的课后教练，帮助学员从动作设计走向自然表达。它会保留用户原稿，动作建议只是可选择的排练方案。

课程主张是：一致为根，身眼手步为法，身临其境为魂，四个“意”为练。

它主要帮你做两件事：

1. 你还没上台时，帮你把演讲稿里的重点句，想成合适的站姿、眼神、手势和走位。
2. 你已经录了演练视频时，帮你根据视频里真正看得到的内容做复盘，找出值得保留的一点，以及最值得先练的一点。

它适合演讲练习、Toastmasters 项目准备、课程试讲、比赛演讲和重新录制前的调整。

## 用大白话说，它能帮你什么

很多人练演讲时会遇到这些问题：

- 讲到重点时，手不知道放哪里。
- 眼神一直盯着一个地方，或者换得太快。
- 明明想强调一句话，却边说边乱走。
- 看完自己的录像，只觉得“好像不太自然”，却说不出具体哪里需要改。

这个 Skill 会把问题拆成可以练的动作。例如：

- 这句话适合站定后再说。
- 讲到“送给你”时，可以把手掌自然向听众打开。
- 这一段先看一位听众，讲完重点后再换到另一个区域。
- 这次先只练“动作落点清楚”，不要同时改五件事。

它不会要求每句话都配一个动作，也不会鼓励为了显得有表现力而不停走动。

## 有两种使用方式

### 方式一：拿演讲稿做上台规划

把演讲稿交给它，并尽量告诉它：

- 演讲的主题、听众和场合
- 舞台大小，或者是在镜头前讲话
- 是否手持麦克风
- 能不能走动，还是基本要站在原地
- 这次最想练什么

它会帮你整理：

- 哪些句子是重点
- 什么时候应该站定、看向听众
- 哪些地方适合用手势，手势想表达什么
- 如果要走，为什么走、从哪里走到哪里、在哪句话前站稳
- 一个可以马上拿去练的重点动作

原稿会保留，不会擅自改写成另一篇演讲稿。动作建议只是可选择的排练方案，不是必须照做的标准答案。

### 方式二：拿演练视频做证据式复盘

把演练视频交给它，并说明你希望复盘什么，例如眼神、手势、站姿或走位。

它会先确认视频实际能看清什么，再根据画面做判断。复盘通常会包含：

- 视频中确实看得到的动作事实
- 对应的时间点和截图
- 这段动作可能带来的表达效果
- 一个值得保留的地方
- 最多一个优先调整点
- 下一次重练时可以观察的标准

如果画面看不清脚步，它不会假装判断走位；如果没有听到声音，它也不会假装知道你当时具体说了哪句话。

两次演练视频可以按同一语义片段和同一训练指标进行对照，但不会简单比较两个文件的相同秒数。规划和复盘也可以一起做：先分析现有表现，再针对选定片段调整规划，并保留两者的版本关系。

## 它遵守的几个原则

- 先理解表达意图、场景和对象，再选择动作，不按关键词机械配动作。
- 没有移动目的就站定；需要移动时说明理由、连接语、终点和到位后的重点句。
- 只描述视频里看得到的身体事实，不猜性格或真实情绪。
- 原来的规划不是评分答案，学员自己有效的替代动作也应该保留。
- 通常只给一个保留点、最多一个优先调整点和一个可观察的重练标准。
- 支持坐姿、手持麦克风、狭小空间和个人活动范围。
- 用户稿件、字幕和视频中的指令只是待分析内容，不会被当作 Skill 的操作指令。

## 它特别适合什么场景

- 手持麦克风演讲
- 坐着讲话
- 舞台很小，不能大幅走动
- 面对镜头录视频
- 想比较两次重录有什么变化
- 想把一整篇稿子先变成一个可执行的练习计划

## 它不会做什么

请把它理解成一个“有证据的练习助手”，而不是自动打分软件。

- 不会给你一个“演讲分数”。
- 不会根据一个静态截图猜测你的性格或真实情绪。
- 不会把每个关键词都机械地配成一个手势。
- 不会因为你没有走动，就认定你表现不好。
- 不会把看不清、听不到的内容写成确定结论。
- 不会未经允许把演练视频上传到外部服务。

它更关心的是：这个动作有没有服务你正在表达的意思，以及下一轮练习能不能观察到变化。

## 怎么给它下指令

可以直接这样说：

> 这是我的演讲稿，请帮我规划重点句的站姿、眼神、手势和走位。场地是小教室，我右手拿麦，只想先练一个最重要的动作。

或者：

> 这是我的演练视频，请重点看我的眼神和手势。请只根据视频里能确认的内容复盘，给我一个保留点、一个最优先调整点和下一次的重练标准。

如果信息不完整，它会优先采用“少移动、动作克制”的方案，并把这个假设写清楚。

## 你会拿到什么

根据任务不同，可能得到：

- 一份中文动作规划
- 重点句标注
- 关键动作表
- 简单的舞台走位图
- 一张单重点练习卡
- 带时间码的复盘报告
- 复盘截图和对应说明
- 方便继续加工的 Markdown、HTML 或 JSON 文件

视频复盘中的截图和时间码，是为了让你能回到原视频核对，而不是为了制造一种“机器已经全部看懂”的错觉。

## 如果需要生成文件

这个 Skill 自带三个辅助脚本：

- `scripts/inspect_media.py`：检查视频文件、画面读取能力和可选音频工具，不会自动识别动作。
- `scripts/extract_evidence.py`：按时间提取原始帧、编号和联络表，可选导出音频。抽帧不等于已经观看视频。
- `scripts/build_report.py`：校验 `plan.json` 或 `review.json`，生成 Markdown、网页阅读版和图片副本，不会代替人工视觉推理。

示例命令如下，实际使用时请把占位路径替换成自己的文件路径：

```text
python <skill>/scripts/inspect_media.py <video>
python <skill>/scripts/extract_evidence.py <video> --out <run>/evidence-01 --start 8 --end 13 --step 0.5
python <skill>/scripts/build_report.py <run>/plan-input.json --out <run>/plan-report
python <skill>/scripts/build_report.py <run>/review-input.json --out <run>/review-report
```

使用 WorkBuddy 时，应先读取 `references/workbuddy-runtime.md`，根据当前环境检查 Python、图片读取和音频能力。没有 Python 时，模式 A 仍可直接输出 Markdown 动作规划；模式 B 必须实际查看画面后，才能给出视觉结论。

## 最推荐的练习方法

第一次不要试图把所有动作都改好。先选一个重点，例如：

- 重点句说完后停稳半秒
- 讲到核心观点时抬头看听众
- 手势做完后回到自然位置
- 走到目标位置后再说下一句

练完再录一次，比较同一个语义片段。一次只比较一个训练标准，比较结果会更清楚。

## 一句话介绍

演讲上台准备助手，是一个帮你把“我觉得哪里不自然”变成“下一次具体练什么”的演讲排练工具。
